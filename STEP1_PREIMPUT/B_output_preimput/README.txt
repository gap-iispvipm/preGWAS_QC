Here you will find a structured folder with the results of the execution of STEP1_PREIMPUT. The structure will be: 
/{BATCH_NAME}_output_preimput
    /1A_output_QC: output QCed files bed/bim/fam 
    /1B_output_DP: output files ready to be uploaded to TOPMed server for imputation
    /1C_output_PCA: output files from PCA analysis and ancestry inference for the single batch (hg19 ref)
